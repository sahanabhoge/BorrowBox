# BorrowBox

### Borrow Anything, Anywhere Near You

BorrowBox is a peer-to-peer rental platform where users can list, discover, and borrow useful items from people nearby.

## Technologies Used
- React
- Vite
- Node.js
- Express.js
- MongoDB

## Features
- User registration and login
- Browse available items
- List and manage personal items
- View item details
- Borrow items from other users
